# 마리나라 발췌 카드 (마개조)

Marinara Engine v2.5.0용 개인 확장입니다. 채팅에서 드래그한 글을 한 장의 PNG 카드로 저장합니다.

## 기능

- **발췌 이미지**: 글을 드래그하면 "로어북에 추가" 버튼 옆에 발췌 버튼이 뜹니다.
- **대사/문단 고르기**: CONVO 채팅은 대사 한 줄씩, RP 채팅은 문단 단위로 체크해서 카드에 넣습니다. 이름은 메시지에서 바로 읽어 와서 말풍선 스타일이어도 동작합니다.
- **형광펜**: 채팅에서 칠하면 채팅별로 저장되고, 발췌 카드에도 그대로 따라옵니다. 모양(형광펜/박스/밑줄)과 진하기, 팔레트(최대 8색)를 바꿀 수 있습니다.
- **카드 디자인 8종**: 클래식, 미니멀, 인용, 노트, 액자, 티켓, 그라데이션, 필름
- **배경 17색 + 직접 고르기**
- 비율(1:1, 4:5, 9:16, 자동), 정렬, 폰트, 글자 크기, 저장 배율(1×–3×), 대화록/말풍선 레이아웃, 정규식 치환

## 설치

마리나라 → 확장 → 개인 확장에서 이 저장소(`https://github.com/lemonpie601/extract`)를 연결하세요.
업데이트된 확장은 비활성 상태로 저장되니, 새 코드를 확인한 뒤 켜 주세요.

## 발췌문 표기법

- `==글자==` : 팔레트 첫 번째 색 형광펜
- `=={#ffd54a}글자==` : 지정한 색 형광펜
- `*글자*` : 흐린 강조, `**글자**` : 굵게
- `[이름]` 다음 줄부터 대사 : 채팅 로그(대화록/말풍선)로 표시
