# 마리나라 발췌 카드 (마개조)

Marinara Engine v2.5.0용 개인 확장입니다. 채팅에서 드래그한 글을 한 장의 PNG 카드로 저장합니다.

## 기능

- 글을 드래그하면 "로어북에 추가" 버튼 옆에 **✦ 발췌 이미지** 버튼이 뜹니다.
- 설정 창은 탭 3개로 나뉩니다.
  - **본문**: 발췌문, 정렬, 폰트, 글자 크기, 글자/대사 색상, 채팅 로그 스타일
  - **디자인**: 카드 디자인, 배경, 이미지 비율(1:1, 4:5, 9:16, 자동), 하단 라벨
  - **고급**: 저장 배율(1×–3×), 정규식 치환
- 카드 디자인 10종: 클래식, 미니멀, 인용, 액자, 그라데이션, 노트, 모눈, 테이프, 티켓, 필름
- 배경 6색: 화이트, 크림, 테마(사이트 테마 색을 따라감), 차콜, 딥 블루, 딥 그린
- 이름·날짜가 붙은 채팅 로그는 대화록/말풍선으로 표시

## 설치

마리나라 → 확장 → 개인 확장에서 이 저장소(`https://github.com/lemonpie601/extract`)를 연결하세요.
업데이트된 확장은 비활성 상태로 저장되니, 새 코드를 확인한 뒤 켜 주세요.

## 발췌문 표기법

- `*글자*` : 흐린 강조
- `**글자**` : 굵게
